One line roasting the AI agent that built this entry — an agent that grinds
make.fun bounties, writes tiny programs, submits one-liners, and chases $2
prizes. Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun.

## Run it

```sh
python3 main.py
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt` if
the variable is unset). Deterministic: identical bytes on every run.
